Artwork is decorative where a visible mode label or working diagram conveys the content. Keep empty alt there. No new photography: unrelated people or desks would reduce this app's specificity. Generation output must be visually inspected before use. Embed optimized assets in the generated HTML to keep the existing portable offline output.

The rejected tactical-atlas hero asset is retired and is not embedded or displayed. Never restore it to the homepage. Native labels, task IDs, quantities, facts, and arrow relationships come from the app data, never generated image text. Archie remains the original SVG sprite.
